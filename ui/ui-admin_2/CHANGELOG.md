# ui-admin_2 CHANGELOG

> ui-admin 的美观重构版 · 功能与 ui-admin 完全对齐(API/store/utils 层零改动),仅重构视图/样式并修复缺陷。

## 视觉与体验

- **全新设计系统** `src/assets/theme.css`:青绿主色 `#14b8a6` + 深空蓝侧栏,统一按钮/卡片/表格/分页/弹窗/表单/下拉/标签/滚动条
- **布局**(`Index.vue`):渐变侧边栏(可折叠)、毛玻璃顶栏、路由切换动画、菜单当前项高亮、点击 Logo 回首页、窄屏隐藏次要信息
- **登录页**(`Login.vue`):渐变背景 + 漂浮装饰、毛玻璃卡片、登录前表单校验、登录按钮 loading、记住用户名(预填)、忘记密码提示、输入框自动聚焦
- **首页看板**(新增 `Home.vue`):问候横幅、6 项数据统计卡片(老人/员工/护理等级/护理计划/护理任务/体检套餐,点击直达)、快捷入口;登录后 `/` 自动落地 `/home`

## 缺陷修复

- 移除老人/用户列表中的**明文密码列**;编辑弹窗不再回显密码,留空=不修改,新增必填初始密码
- 修复顶栏「更换头像」跳转到不存在路由(现打开含头像上传的基本资料弹窗)
- 修复权限管理新增/删除"失败也报成功并关闭/刷新"、角色分配权限失败无提示
- 按钮权限空配置时不再把「添加/批量删除」全部禁用(兼容种子数据;配置后仍精确控制)
- 全库清除 `console.log` / `debugger`
- 表单必填拦截:标签/角色(编码、名称)、护理与体检各主数据(名称)、护理计划(名称、老人、日期先后)、权限(名字)

## 一致性打磨

- 各页头部按钮图标统一(`Plus`/`Delete`),权限页按钮风格统一
- 头像/图片列空值占位(`el-avatar` 默认头像、`el-image` 预览),无破图
- 「分配角色/分配标签」弹窗底部操作区与全局统一(取消-主按钮)
- 新增数据默认状态:启用/排序 0/结果类型文本等,避免空表单
- 主题配色统一(用户状态开关等硬编码色改为 CSS 变量)

## 性能与工程

- 路由**懒加载分包**:主包 1308KB→1199KB,每页独立 chunk(Home/Elder/CarePlan 等 4~11KB)
- 弹窗内容超高自动滚动(`max-height:62vh`)
- `vite.config.js` 提高 chunk 告警阈值(Element Plus 全量引入体积所致)
- 响应式:≤900px 隐藏顶栏次要信息、≤768px 卡片内边距收窄
- 新增项目 `README.md`(功能/启动/结构/设计说明)
